# Atlas frontend

React/Vite interface for Atlas. See the [project README](../README.md) for features, architecture, database prerequisites and complete setup.

From this directory:
```bash
npm ci
npm run dev
```

Other commands: `npm run build`, `npm run preview`, `npm run lint`.

See [.env.example](.env.example) for hosted API configuration. Localhost development currently uses API port 3000.
